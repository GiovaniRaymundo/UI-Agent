# UI-Agent

Skills de diseño de interfaces para agentes de código.

## Skills

| Skill | Descripción |
| --- | --- |
| `ui-design` | Diseño, auditoría y refactor de UI: leyes de UX, patrones, Atomic Design, jerarquía visual, estados, accesibilidad, auditoría de skeletons con Playwright y extracción de fuentes. |

## Instalar

```bash
npx skills add GiovaniRaymundo/UI-Agent --skill ui-design
```
